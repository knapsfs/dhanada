# Decisions and open questions

Status: Live. Last updated: 2026-11-16.

This folder records the design choices that have been accepted, proposed, or deferred. It separates decisions from unresolved questions so the model stays reviewable and changeable without losing the rationale behind it.

## What this layer answers

- Which design choices are accepted and why?
- Which issues remain open, deferred, or proposed?
- What is the current business position for each significant design decision?

## Rule of use

- Keep business policy in the ADRs.
- Keep unresolved items in the open-questions register.
- Keep examples in the example folder and implementation notes in the data-model layer.
