# Product layer

Status: Draft. Last updated: 2026-11-16.

This folder defines the business purpose, scope, and operating assumptions of the Dhanada platform. It is the starting point for the design set and should be read before any domain or data work.

## Read in order

1. [vision-and-scope.md](vision-and-scope.md): business context, scope, and non-goals.
2. [personas-and-roles.md](personas-and-roles.md): actors, responsibilities, and organizational context.
3. [requirements.md](requirements.md): functional and non-functional requirements by module.
4. [glossary.md](glossary.md): common terminology and naming rules.

## What this layer answers

- Why does the business exist?
- What is in scope and what is not?
- Which roles matter to the operating model?
- Which requirements are decided, proposed, or still open?
